# Vibe Coding 學習資源

**Vibe Coding（氛圍程式設計）** 是以自然語言描述需求、由 AI 產生並修改程式碼的開發方式。開發者的工作重心從逐行撰寫程式碼，轉移到釐清需求、驗證結果與持續修正。

## 什麼是 Vibe Coding

Vibe Coding 的主要特點：

- **以自然語言溝通**：透過對話描述功能，由 AI 產生對應的程式碼。
- **快速驗證**：在短時間內做出可運作的原型，並依回饋調整。
- **人機分工**：AI 負責產出程式碼，開發者負責判斷方向與品質。
- **聚焦產品本身**：將更多時間投入在功能與使用者體驗。

需要注意的是，AI 產生的程式碼仍可能有錯誤或安全問題。專案規模越大，越需要具備基本的程式理解能力，才能有效審查與維護。

## 常用工具

以下工具的學習門檻分為低、中、高三級，供選擇工具時參考。

### AI 開發環境

#### 1. Cursor：AI 程式碼編輯器

- **特點**：以自然語言修改程式碼、理解整個專案的上下文、可自動執行多步驟修改
- **適用情境**：全端開發、程式碼重構、既有專案維護
- **學習門檻**：中（建議具備程式基礎）
- **網站**：[https://cursor.com](https://cursor.com)

#### 2. Replit：雲端開發平台

- **特點**：在瀏覽器內開發、支援多種程式語言、內建 AI Agent 與部署功能
- **適用情境**：教學、快速原型、初學者練習
- **學習門檻**：低（無須安裝與設定環境）
- **網站**：[https://replit.com](https://replit.com)

### AI 應用生成平台

#### 3. Lovable：全端應用生成平台

- **特點**：以自然語言描述即可產生完整網頁應用，並可直接部署
- **適用情境**：網站開發、產品原型、非技術背景使用者
- **學習門檻**：低
- **網站**：[https://lovable.dev](https://lovable.dev)

#### 4. Bolt.new：瀏覽器內全端開發環境

- **特點**：由 StackBlitz 開發，可在瀏覽器內生成、預覽並修改全端應用
- **適用情境**：快速原型、前端開發、教學示範
- **學習門檻**：低
- **網站**：[https://bolt.new](https://bolt.new)

#### 5. v0：Vercel 的 AI 應用生成工具

- **特點**：以自然語言產生 React 元件與頁面，可即時預覽並匯出程式碼
- **適用情境**：UI 原型、元件設計、前端開發
- **學習門檻**：低
- **網站**：[https://v0.app](https://v0.app)

### 程式開發輔助

#### 6. GitHub Copilot：程式碼助手

- **特點**：程式碼自動補全、對話式問答、支援多種編輯器
- **適用情境**：日常開發、程式碼最佳化、學習程式設計模式
- **學習門檻**：中
- **網站**：[https://github.com/features/copilot](https://github.com/features/copilot)

#### 7. Cline：VS Code 擴充套件

- **特點**：在 VS Code 中以 AI Agent 方式讀取專案、修改檔案並執行指令，可選用不同的模型供應商
- **適用情境**：程式碼審查、除錯、多檔案修改
- **學習門檻**：中
- **安裝**：於 VS Code 擴充功能市集搜尋「Cline」

### 部署平台

#### 8. Vercel：前端部署平台

- **特點**：連結 Git 儲存庫即可自動部署、全球 CDN、預覽環境
- **適用情境**：Next.js 等前端框架、靜態網站、全端應用
- **學習門檻**：低
- **網站**：[https://vercel.com](https://vercel.com)

#### 9. Netlify：網站部署平台

- **特點**：靜態網站託管、Serverless Functions、表單處理
- **適用情境**：JAMstack 應用、靜態網站
- **學習門檻**：低
- **網站**：[https://netlify.com](https://netlify.com)

## 學習路徑

以下時間僅供參考，實際進度取決於投入時間與既有背景。

### 入門（0–3 個月）

- **工具**：Lovable、Replit
- **學習重點**：HTML／CSS 基本概念、簡單的 JavaScript 互動、AI 輔助開發的基本流程
- **實作專案**：個人網站、Landing Page

### 中階（3–6 個月）

- **工具**：Cursor、v0、Vercel
- **學習重點**：React 基礎、API 串接、響應式設計
- **實作專案**：待辦事項應用、部落格系統

### 進階（6 個月以上）

- **工具**：Cursor、GitHub Copilot、雲端服務
- **學習重點**：全端開發、資料庫設計、部署與維運
- **實作專案**：電商平台、社群應用

## 開發實務建議

### 開發流程

1. **描述需求**：清楚說明要實現的功能、使用情境與限制條件。
2. **產生初版**：由 AI 產生程式碼，先求能運作。
3. **小步迭代**：每次只調整一個功能，完成後立即測試。
4. **審查程式碼**：確認 AI 產出的程式碼符合預期，特別是資料處理與權限相關的部分。
5. **版本控制**：以 Git 保存每個可運作的版本，出錯時能快速還原。

### 需要培養的能力

- **需求拆解**：將大需求拆成 AI 能準確完成的小任務。
- **程式理解**：能讀懂並判斷 AI 產出的程式碼。
- **使用者體驗**：了解基本的 UI／UX 原則。
- **前端基礎**：HTML、CSS、JavaScript 的基本知識。
- **部署流程**：了解從開發到上線的基本步驟。

## 建立新專案

以常見框架建立專案後，再交由 AI 工具協助開發：

```bash
# Vite + React
npm create vite@latest my-vibe-project -- --template react
cd my-vibe-project
npm install
npm run dev

# Next.js
npx create-next-app@latest my-next-project
cd my-next-project
npm run dev
```
