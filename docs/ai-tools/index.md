# 熱門推薦 AI 工具

本頁整理目前常用的 AI 工具，說明各自的主要用途、特點與適用對象，並在文末提供依職務區分的工具組合建議。

## 工具一覽

### 1. ChatGPT：通用型對話 AI

- **用途**：文字撰寫、程式開發輔助、問題解答、構思發想
- **特點**：中文能力良好，適用情境廣泛
- **適用對象**：一般使用者、學生、開發者、內容創作者
- **網站**：[https://chatgpt.com](https://chatgpt.com)

### 2. GitHub Copilot：程式碼助手

- **用途**：即時程式碼建議、自動補全、程式碼生成
- **特點**：直接整合於 VS Code、JetBrains 等主流編輯器
- **適用對象**：程式設計師、軟體工程師
- **網站**：[https://github.com/features/copilot](https://github.com/features/copilot)

### 3. Claude：Anthropic 開發的 AI 助手

- **用途**：長篇文件分析、程式開發、複雜推理任務
- **特點**：擅長處理長篇內容與程式碼
- **適用對象**：研究人員、內容分析人員、開發者
- **網站**：[https://claude.ai](https://claude.ai)

### 4. Gemini：Google 的多模態 AI

- **用途**：文字生成、程式開發、圖像理解、資料處理
- **特點**：可同時處理文字、圖像與程式碼，並與 Google Workspace 整合
- **適用對象**：開發者、研究人員、資料分析人員
- **網站**：[https://gemini.google.com](https://gemini.google.com)

### 5. Cursor：AI 程式碼編輯器

- **用途**：程式碼撰寫、專案重構、程式碼解說
- **特點**：編輯器內建 AI，可用自然語言描述修改需求
- **適用對象**：程式設計師、軟體工程師
- **網站**：[https://cursor.com](https://cursor.com)

### 6. Midjourney：圖像生成

- **用途**：圖像生成、視覺創作、設計參考
- **特點**：輸出品質高，風格控制能力強
- **適用對象**：設計師、藝術創作者、內容創作者
- **網站**：[https://midjourney.com](https://midjourney.com)

### 7. Notion AI：筆記與工作空間

- **用途**：文件撰寫、內容摘要、任務管理
- **特點**：直接在 Notion 工作空間中使用
- **適用對象**：團隊協作、個人知識管理
- **網站**：[https://notion.so/product/ai](https://notion.so/product/ai)

### 8. DeepL：翻譯工具

- **用途**：文件翻譯、多語言溝通
- **特點**：譯文自然流暢，適合正式文件
- **適用對象**：跨國工作者、語言學習者、研究人員
- **網站**：[https://deepl.com](https://deepl.com)

### 9. Perplexity：AI 搜尋引擎

- **用途**：資訊搜尋、資料研究、事實查證
- **特點**：回答附上來源連結，便於查核
- **適用對象**：研究人員、學生、記者
- **網站**：[https://perplexity.ai](https://perplexity.ai)

### 10. Runway：影片生成與編輯

- **用途**：影片生成、影像編輯、特效製作
- **特點**：提供多種影片生成與編輯模型
- **適用對象**：影片創作者、廣告製作、社群經營
- **網站**：[https://runwayml.com](https://runwayml.com)

### 11. Gamma：簡報製作

- **用途**：簡報製作、文件設計、內容規劃
- **特點**：依文字大綱自動生成排版完整的簡報
- **適用對象**：商務人士、教育工作者、學生
- **網站**：[https://gamma.app](https://gamma.app)

### 12. NotebookLM：Google 的研究助手

- **用途**：文件分析、研究筆記整理、資料摘要、語音摘要生成
- **特點**：以使用者上傳的資料為依據回答問題，並標示出處
- **適用對象**：研究人員、學生、內容創作者
- **網站**：[https://notebooklm.google.com](https://notebooklm.google.com)

### 13. Google AI Studio：Google 的 AI 開發平台

- **用途**：模型測試、API 開發、原型製作
- **特點**：可免費試用 Gemini API，適合快速驗證 AI 應用
- **適用對象**：AI 應用開發者、研究人員
- **網站**：[https://aistudio.google.com](https://aistudio.google.com)

### 14. Nano Banana：Google 的圖像生成與編輯模型

- **用途**：圖像生成、以文字指令修改圖片、多張圖片合成
- **特點**：修改圖片時能維持人物與物件的一致性
- **適用對象**：設計師、內容創作者、行銷人員
- **使用方式**：透過 Gemini App 或 Google AI Studio 使用

## 如何選擇 AI 工具

| 使用者類型 | 建議組合 |
| --- | --- |
| 程式開發者 | ChatGPT、GitHub Copilot、Cursor |
| AI 應用開發者 | Google AI Studio、Gemini、Claude |
| 內容創作者 | ChatGPT、Midjourney、Notion AI |
| 視覺與行銷 | Gemini（Nano Banana）、Midjourney、Gamma |
| 研究與學習 | NotebookLM、Claude、Perplexity |
| 商務工作者 | ChatGPT、Gamma、Notion AI |
| 多語言工作者 | Gemini、DeepL、Claude |

## 發展趨勢

目前值得關注的 AI 發展方向：

1. **多模態**：同時處理文字、圖像、語音與影片，例如 Gemini。
2. **裝置端 AI**：在個人裝置上執行模型，降低延遲並保護隱私。
3. **垂直領域**：針對特定產業與專業領域設計的工具。
4. **團隊協作**：AI 直接整合於團隊工作流程與協作平台。
5. **研究輔助**：以使用者提供的資料為基礎進行分析，例如 NotebookLM。

## 入門建議

- **初次使用**：從 ChatGPT 開始，熟悉基本的對話與提問方式。
- **開發者**：導入 GitHub Copilot 或 Cursor，提升日常開發效率。
- **AI 應用開發者**：透過 Google AI Studio 了解 Gemini API 的使用方式。
- **創作者**：以 Midjourney、Nano Banana 與 Runway 處理圖像與影片需求。
- **商務人士**：以 Notion AI 與 Gamma 處理文件與簡報。
- **研究人員**：以 NotebookLM 整理文獻，以 Claude 或 Gemini 處理複雜分析。
