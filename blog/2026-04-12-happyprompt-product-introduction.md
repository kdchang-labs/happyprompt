## HappyPrompt 是什麼？

**HappyPrompt** 是一款 Chrome 擴充套件，專門解決「AI Prompt 難以管理」的痛點。

用最簡單的一句話描述它：**一個你的個人 AI 提示詞管理庫，讓你在任何 AI 平台上都能一鍵取用。**

不用再翻聊天紀錄、不用記在 Notion、不用複製貼上——打開擴充套件，搜尋，插入，完成。

---

## 為什麼你需要管理你的 Prompt？

隨著 ChatGPT、Claude、Gemini 等 AI 工具快速普及，越來越多人開始意識到：**Prompt 的品質，決定了 AI 輸出的品質。**

一個好的 Prompt 可以讓 AI 直接產出你要的結果，而不需要來回調整五六次。

但問題是——好的 Prompt 很難一次到位，往往需要不斷打磨。當你好不容易調教出一個高效的提示詞，如何保存它，讓下次繼續使用？

這就是 HappyPrompt 存在的理由。

---

## 核心功能介紹

### ⚡ 一鍵儲存 Prompt

看到好用的 Prompt，或是剛調好的提示詞，直接點擊儲存。支援標題、內容、Tags 分類，讓你的提示詞有條有理，不再散落各處。

### 💡 一鍵插入到 AI 平台

完美整合 **ChatGPT、Claude、Gemini** 等主流平台。不需要手動複製貼上，點擊「插入」，Prompt 直接填入輸入框，立即送出。

### 🔍 強大搜尋系統

支援標題、內容全文、Tags 三種搜尋方式。就算你存了幾百個 Prompt，也能在幾秒內找到你要的那一個。

### 📚 內建 100+ 跨職能提示詞庫

不知道怎麼寫 Prompt？直接用我們幫你準備好的！

內建涵蓋以下職能的專業提示詞：

| 職能 | 範例 |
|------|------|
| 行銷 | 社群文案、SEO 文章、廣告腳本 |
| 工程 | Code Review、技術文件、Debug 助手 |
| PM | PRD 撰寫、用戶故事、功能規格 |
| 人資 | 招募 JD、績效面談引導、員工 onboarding |
| 業務 | 開發信、提案簡報、客戶溝通腳本 |
| 財務 | 數字報告解讀、預算規劃分析 |
| 客服 | 回覆範本、投訴處理流程 |

無論你是哪種職能，都有現成的提示詞可以直接套用，讓 AI 立刻產出專業級成果。

### 🔒 免登入，資料完全本地化

**不需要註冊帳號、不需要登入。**

所有資料完全儲存在你的本地瀏覽器中，不上傳到任何伺服器，隱私零疑慮。

### 📤 支援匯出與匯入

資料要備份？換電腦？或想分享給同事使用？

一鍵匯出成 .csv 檔案，隨時匯入，輕鬆備份或團隊共享。

## 如何開始使用？

1. 前往 Chrome Web Store，搜尋「**HappyPrompt**」，或直接點擊下方連結安裝
2. 安裝後，點擊瀏覽器右上角的擴充套件圖示，即可打開 HappyPrompt
3. 從內建 Prompt 庫選擇你需要的提示詞，或新增自己的
4. 開啟 ChatGPT（或 Claude、Gemini），點擊「插入」，開始和 AI 對話

就這麼簡單。**完全免費，無需帳號，開箱即用。**
